# Environment and AI Toolchain

## Project Overview

Final-year capstone project investigating how development environments and AI-assisted tooling can be combined into a coherent, reproducible workflow.

**Problem:** Developers often configure local environments and AI tools separately, with little documentation tying the two together. This project asks how those pieces can be integrated so setup, usage, and design choices are transparent to an evaluator.

**Intended deliverables:**
- A documented, reproducible development environment
- Integration of AI toolchain components into that environment
- Written rationale for key design decisions (README, commit history, and inline comments)

Language, framework, and architecture choices are still being finalised — see [Stack](#stack) below.
